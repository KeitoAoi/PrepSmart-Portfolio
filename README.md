# PrepSmart AI

PrepSmart AI is an AI-powered mock interview platform developed as a team project for **ICSI 518 – Fall 2024**.

The platform is designed to help users practice technical and coding interviews in an interactive environment using AI-assisted evaluation and interview simulation features.

## Tech Stack

- React.js
- Node.js
- Express.js
- Gemini AI
- Firebase
- JWT
- REST APIs

## Key Features

- AI-powered mock interview simulation
- Coding and technical interview practice
- AI-based response and code evaluation
- User authentication and authorization
- Interview session management
- Video and speech-based interview functionality
- REST API-based frontend and backend communication

## Running the Project Locally

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm start
```
